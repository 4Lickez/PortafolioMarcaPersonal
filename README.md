## Sobre este proyecto

Este repositorio reúne la evidencia del Proyecto No. 1: *Marca personal profesional en la era digital*, desarrollado como trabajo en equipo. El objetivo es analizar la importancia de la marca personal profesional como herramienta estratégica para destacar el valor individual, construir una reputación sólida y generar oportunidades laborales, comerciales y de networking a través de medios digitales.
